<h1>ATM Application Machine State</h1>
<p>This application provides a GUI for performing operations of an ATM</p>

<h2>Features:</h2>
<ul>
  <li>Insert card into the ATM.</li>
  <li>Enter PIN for card verification.</li>
  <li>Select from various transaction options (Deposit, Withdraw, Transfer,Account Info).</li>
  <li>Perform transactions securely.</li>
</ul>

<h2>Functionality:</h2>
<ul>
  <li>Inserting a card triggers the ATM to check and verify the card.</li>
  <li>Entering a PIN initiates the verification process for the inserted card.</li>
  <li>Depositing money: Allows users to input the amount of money to deposit into their account.</li>
  <li>Withdrawing money: Enables users to input the amount of money they want to withdraw from their account.</li>
  <li>Transferring money: Permits users to transfer money to another account by providing the recipient's account number and the amount.</li>
  <li>Verifying account information: Displays account details such as balance, account number, etc., after successful login.</li>
</ul>
